# Third-party binaries removed before publishing

These jars were in `libs/` when the project shipped and were removed to avoid redistributing vendor SDKs. Build files still reference them.

- `libs/android-support-v13.jar`
- `libs/annotations.jar`
- `libs/droidprism.jar`
- `libs/gson-2.2.4.jar`
- `libs/jsoup-1.7.3.jar`
- `libs/jsr305-1.3.9.jar`
